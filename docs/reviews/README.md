# Design Reviews

Store independent architecture and technical-route reviews in this directory.

Reviews describe evidence, risks, alternatives, required changes, and a clear
decision. Implementation code belongs in the relevant `src/`, `configs/`, and
`tests/` folders, not in a review commit.
